# Your Tour

## Description
Your Tour is a responsive one-page website created as a test assignment.
The project demonstrates semantic HTML, responsive layout, and basic JavaScript interactions.

The layout is implemented for three breakpoints:
- Desktop
- Tablet
- Mobile
  
## Tech Stack
- HTML5
- CSS3 (Sass / SCSS)
- JavaScript (ES6)
- BEM methodology
- Flexbox

## Features
- Responsive layout for desktop, tablet, and mobile viewports
- Pixel-perfect layout based on the provided design
- Sass structure with variables, nesting, and mixins
- Basic JavaScript for fixed header with animations, form validation

## Live Demo
The application is deployed to Github Pages: 

👉 https://ergo-pr0xy.github.io/your-tour/

## Local Usage
The project is a static website and can be opened locally without any build steps.

1. Clone the repository
2. Open `index.html` in your browser

## Development
To modify styles using SCSS, you need Node.js, and npm installed.

1. Install dependencies
```bash
npm ci
```
2. Run Sass watcher
```bash
npm run sass-watch
```
